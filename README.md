# Talent Tap - PWA

A Progressive Web App to share and discover amazing talents!

## Features

✨ **Core Features:**
- Post your talents with name and skill
- View all posted talents in real-time
- Delete talents you no longer want to share
- Real-time talent counter
- Data persists with localStorage

🚀 **PWA Features:**
- Install on home screen (iOS & Android)
- Works offline
- Fast loading
- App-like experience

## Installation

### Web Browser
1. Clone the repository:
   ```bash
   git clone https://github.com/maneeshmunagala15/Talent-Tap.git
   cd Talent-Tap
   ```

2. Open `index.html` in your browser

### Install as App

**On Android:**
1. Open in Chrome/Firefox
2. Tap menu (⋮) → "Install app"
3. Tap "Install"

**On iOS:**
1. Open in Safari
2. Tap Share → "Add to Home Screen"
3. Tap "Add"
